# Release Notes — v1.91.0.0.1.1

> Date: 2026-10-26 · Target upstream: Boost 1.91.0 (`BOOST_VERSION 109100`)
> **Stable patch release** (modules wrapper version 0.1.1) and the **final release of this
> repository's Boost 1.91.0 line**. Module/feature counts and the consumable surface are
> **identical** to `1.91.0.0.1.0`; the only change is the deprecation notice and the hand-over
> described below.

## 1. This Repository Is No Longer Maintained

The Boost modules wrapper has moved to **[mcpplibs/boost-m](https://github.com/mcpplibs/boost-m)**,
and the package is now published under the name **`mcpplibs.mwrap.boost`**. Development,
fixes and boost-version upgrades happen there; this Boost 1.91.0 line is frozen (tag
`v1.91.0.0.1.0` remains valid and immutable).

Migration is required rather than optional for anyone who wants further updates:

| | This repository (frozen) | Successor |
|---|---|---|
| Source | `ZheFeng7110/boost-module` | [`mcpplibs/boost-m`](https://github.com/mcpplibs/boost-m) |
| Package name | `ZheFeng7110.boost` | **`mcpplibs.mwrap.boost`** |
| Latest release | `v1.91.0.0.1.1` (this tag) | see the new repository's releases |

The new repository's README carries the current dependency declaration; use the package
identity above and follow its instructions. The C++ API spelling (`import boost.<lib>;` /
`import boost;`, exported `boost::` entities) is unchanged by the move.

## 2. What Is This

C++23 named modules wrapper for the Boost libraries built with the
[mcpp](https://github.com/mcpp-community/mcpp) build tool: consumers write
`import boost.filesystem;` (or the umbrella `import boost;`); the API spelling is identical
to upstream, no `#include` needed. The wrapper layer is BSL-licensed, as is Boost upstream.

This release follows `1.91.0.0.1.0` (2026-09-22) and changes no module, feature, count or
exported symbol. For the full library-by-library known-limitation disclosure, see
[`v1.91.0.0.1.0`](v1.91.0.0.1.0.md) and the first stable release
[`b1.91.0w0.0.0`](b1.91.0w0.0.0.md); they apply unchanged.

## 3. Changes Since v1.91.0.0.1.0

- **Build-time advisory**: `build.mcpp` now calls `mcpp::warning(...)` on every run that
  reaches it, stating that the library is no longer maintained, naming the successor
  repository and the new package name. The advisory is attributed to the package, does not
  fail the build, and is replayed by mcpp on a build-cache hit; a whole-project no-op build
  still prints nothing (it never reaches the `build.mcpp` stage) — touch a source to see the
  advisory again.
- **Documentation**: `README.md`, `README_zh.md`, `docs/usage.md` and `docs/zh/usage.md`
  lead with the deprecation/migration notice.
- **Version**: `[package].version` is now `1.91.0.0.1.1`; consumer examples and the release
  runbook point at tag `v1.91.0.0.1.1`.

No module, feature, count, or API changes; the supported library set is unchanged.

## 5. Known Limitations

Unchanged from `v1.91.0.0.1.0`, which keeps the full disclosure from
[`b1.91.0w0.0.0§4`](b1.91.0w0.0.0.md#4-known-limitations-full-disclosure): gcc 16.1 defect
family, clang/llvm source-location cap with `features = ["all"]`, pure include-only library
list, mingw / real MSVC not guaranteed. See also
[architecture doc §4](../architecture.md#4-known-limitations-consumer-notes).

## 6. Reporting Issues

This repository no longer accepts fixes. Report problems against
[mcpplibs/boost-m](https://github.com/mcpplibs/boost-m); the wrapper-vs-compiler-defect
guidance (attach compiler + platform + dependency declaration + a minimal reproducing TU
for wrapper problems, a minimal reproduction for compiler ICEs) carries over unchanged.
